Основные проблемы и потребности бизнеса на данный момент:
  1. Нарушен контроль данных
    - Есть несколько точек регистрации нового клиента, координации между этими точками нет.
    - Внутренние потоки данных между IT-продуктами контролируются не системно. Ограничения по передаваемым данным в основном обусловлены бизнес-процессами между взаимодействующими IT-продуктами.
    - Со стороны систем обработки данных нет ограничений на доступ к данным.

  2. Проблемы с API партнеров
    - Контракты API содержат категории данных, которые явно предоставляют персональные данные.
    - Некоторые контракты позволяют внешним пользователям выполнять действия и получать данные, к которым у них не должно быть доступа.

  3. Повысить уровень удовлетворённости клиентов.
    - Компания столкнулась с жалобами клиентов: они видят в приложении ошибки, когда заходят в личный кабинет.
    - Там иногда могут отображаться данные другого клиента

  4. Компания не может расширять направление обработки данных.
    - Сейчас проблема управления и хранения потоков данных блокирует реализацию новых продуктов, основанных на данных.

  5. Отреагировать на инциденты и рыночные изменения.
    - Недавно у конкурента произошла утечка данных. Руководство PropDevelopment хочет предотвратить подобные инциденты.

  6. Проверить соответствие требованиям законодательства
    - Сейчас нет уверенности в том, что все текущие бизнес-процессы компании соответствуют законодательным нормам. 

Т.е. основные проблемы - это контроль доступа и безопасность данных + защита от инцидентов.
Исходя из этого я решил провести аудит по следующим разделам:
  - Управление доступом
  - Безопасность данных
  - Защита инфраструктуры
  - Управление инцидентами
